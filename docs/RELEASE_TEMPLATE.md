## 文件校验

下载同版本 `.sha256` 文件，并使用 PowerShell 执行：

```powershell
Get-FileHash '.\SprintAI-vX.Y.Z-windows-x64.exe' -Algorithm SHA256
```

确认输出与 `.sha256` 文件一致
