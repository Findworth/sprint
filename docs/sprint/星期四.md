# 本文件的内容：在一天内创建出虚拟产品，也就是一个简单的产品原型，这个原型应该包括星期三决定的分镜的产品的主要功能和主要流程，为什么要快速制作这个原型？当你投入很长时间在一件事情上，那么你心理就越难接受否定的结果，你也就不会有心境去修改产品了，但当你投入较少的时间，你反而会更容易接受否定的结果，你也就更容易修改产品

## 创建虚拟产品
创建虚拟产品的所需的心态：
    1. 从追求十全十美到差强人意，从追求长期质量到临时模拟
    2. 任何东西都是可以建模的
    3. 原型内容要恰到好处，不能过多：原型是用来回答疑问的，所以要让重点突出，不需要创建出功能齐全的产品
    4. 原型要足够真实
    5. 在团队中，需要选择2个人或以上来担任制作者，也就是制作星期三分镜脚本的原型
