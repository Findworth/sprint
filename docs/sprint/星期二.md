# 本文件的内容：
    在确定最终冲刺目标，和流程图中的重点后，找出实际的解决方案

## 发现点子(点子也就是解决方案，且针对最终冲刺目标，和流程图中的重点)
1. 伟大的发明都是建立在已有的点子(行业内类似的解决方案)之上的，只是改变了看问题的角度，可以借鉴已有的点子，但是绝对不可以照搬
2. 在发现点子时，除了在同一行业进行寻找，还可以扩大搜索范围，重点关注其他领域的类似问题解决方案
发现点子的流程：
    1. 团队成员首先回顾星期一整理的笔记和白板上的内容
    2. 回顾之后，各自分别独立(不能交流)列出所有可能的点子，除了在同一行业进行寻找，还可以扩大搜索范围，重点关注其他领域的类似问题解决方案
    3. 在分别列出点子之后，团队内成员对各自的每个点子进行介绍，评估其可行性，评估其与最终冲刺目标的符合程度
    4. 团队中所有成员必须时刻保持记笔记的习惯，将有兴趣的点子记录下来(这里记笔记的原则和之前接受上下文不一样，直接记录点子即可，不需要遵守"我们应该如何"的原则)
    5. 对点子进行整理，筛选高质量点子

## 分配人员
针对最终冲刺目标和流程图中的重点，分配人员去解决，这里需要遵守以下原则：
    1. 首先判断任务是否是低耦合的，如果是低耦合的，则分组完成，反之则团队一起完成
    2. 确定好分组之后，将每个版块对应的人员挂到流程图中的对应位置

## 开始完成任务
1. 在确定人员分配之后，每个版块对应的负责人开始完成任务，在完成任务的过程中，需要遵守以下原则：
    1. 原则：一起独立工作，也就是对于独立的不同版块的负责人之间在完成任务时保持独立，不得与负责其他独立板块的人进行交流，此时已经不需要头脑风暴，真正需要进行头脑风暴的是每个独立的人
    2. 每个版块的负责人具体执行任务的流程：
        1. 回顾之前的冲刺问题，笔记和收集的点子等等，利用上网搜索主动收集信息
        2. 利用获得的信息快速启动，探索初步想法，想法需要通过草图(极简原型图，设计图)来实现/体现。(草图总是包含用户和用户在使用产品时将会看到的内容)
        3. 在第二步产生的想法之上，进行修改，挑选出最看好的几个想法，并且探索备选方案(也就是优先级)
        4. 为每个想法起一个标题，方便区别

## 引导者在星期二中的作用：
1. 时刻提醒大家时间：引导者手里拿着秒表。引导者必须铁面无私地喊停。这迫使团队保持节奏，快速前进。
