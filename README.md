# SprintAI

> 一个人，也能带领一支 AI 团队完成一场设计冲刺

## 为什么做 SprintAI

一个人或小团队很难同时拥有产品、设计、工程、市场等完整角色，却仍然需要把一个模糊想法认真推演成一个敢于继续投入的方案

只和通用 AI 聊天，往往还会踩进这些坑：

- **提问受认知限制**：问不准就多绕几轮，甚至走偏方向
- **要对齐真人时协作断点**：同事、专家、用户的回答不容易直接进入对话，人机协作效率低
- **视角单一**：单一角色、单一角度，容易走进死胡同；篇幅有限，多轮之后才勉强得到可用结论
- **结论难沉淀**：关键知识点散落在聊天记录里，事后复盘如大海捞针，也难以沉淀成可复用的方法或资产
- **模型能力碎片化**：不同模型各有优劣，却很难在同一流程里协同发挥

临时凑齐一支真人团队成本高、协调慢；通用对话又缺少角色分工、流程纪律与持续沉淀

SprintAI就是这段从「脑中有个想法」到「手上有套方案」之间的**团队与方法缺口**——不是再做一个聊天窗口，而是把设计冲刺变成可执行的工作流

## SprintAI 是什么

SprintAI 是一款多智能体设计冲刺应用，将Google设计冲刺方法改造成适合 AI 团队执行的结构化工作流

你可以带领由引导者、决策者和不同专业角色组成的 AI 团队，与它们共用一块实时白板，从定义问题、发散方案一路推进到决策收敛。

AI 补齐角色、视角和流程纪律；最终方向始终由你决定

## 一场 SprintAI 冲刺如何进行

### 1. 定义问题

围绕长期目标、冲刺问题、用户旅程和真实用户输入，先把问题看清楚

细节与原则见 [星期一](docs/sprint/星期一.md)

### 2. 发散方案

多个智能体独立思考、分享点子、互相补充，再筛选和细化值得继续的方案

细节与原则见 [星期二](docs/sprint/星期二.md)

### 3. 决策收敛

通过方案批判、独立投票和理由说明逐步收敛，由你完成最终拍板，并生成故事板

细节与原则见 [星期三](docs/sprint/星期三.md)

### 4. 制作原型

用最少投入做出足够真实的虚拟产品，回答关键疑问，而不是追求功能齐全

细节与原则见 [星期四](docs/sprint/星期四.md)

## 核心功能

- **多智能体群聊**：不同角色的 AI 与你在同一群聊里轮番发言，打破单一视角与死胡同
- **白板自动沉淀**：发言中的关键结论、预期产出自动上墙，对话不再散落在聊天记录里
- **高效人机协作**：可邀请目标用户、同事或专家入场；用结构化问题承接真人回答，再回到流程
- **AI Native 流程图**：智能体原生操作流程图
- **结构化冲刺 SOP**：内置参考 Google Design Sprint 的讨论流程，强引导、不跑题，确保最初目标有实际产出；也支持普通轮番群聊，以及定制讨论 SOP
- **角色与流程可定制**：按场景配置智能体角色，适配不同团队习惯
- **资产沉淀（持续演进）**：把结论、SOP 与可复用方法沉淀下来，逐步形成团队可复用的智能体与方法论资产
- **阶段检查点与独立投票**：关键节点审阅确认；独立投票与理由说明减少从众，判断可追溯
- **用户最终拍板**：AI 提供建议与纪律，产品方向始终由你决定

## 为什么选择 SprintAI

SprintAI 的价值不在能力上限的演示，而在于**可预期地帮你把事情做的更好**

### 真实价值：你雇它完成什么

- **补齐缺位的团队角色**：不必临时凑齐产品、设计、工程、市场，也能按分工推进讨论与批判
- **把方法变成可执行流程**：问题定义 → 发散 → 收敛 → 故事板，每一步有输入、输出与时间盒，减少「聊了很多却落不了地」
- **产出可带走、可继续加工**：白板、流程图、方案与故事板是结构化成果，不是散落在聊天记录里的观点碎片
- **真人与 AI 可在同一条链上协作**：需要对齐同事、专家或用户时，用结构化问题接入，再回到冲刺节奏


### 确定性：为什么结果可预期

通用对话的不确定性来自三件事：你要自己发明方法、自己维持节奏、自己判断这次输出能不能用。SprintAI 用流程把这三件事变成默认行为：

- **稳定的工作流承诺**：同一套冲刺 SOP 反复跑，你能预知下一环节要产出什么，而不是每次重新组织提问
- **引导者不跑题**：强引导把讨论锁在最初目标上，减少多轮之后才勉强凑出结论的情况
- **阶段检查点**：关键节点先审阅、修改、确认，再前进——质量波动被拦在环节边界，而不是攒到最后才发现走偏
- **独立投票与理由可追溯**：收敛过程可解释，降低从众与「感觉对就行」的偶然性
- **可复用的沉淀路径**：结论与方法能留在白板与资产侧，下次不必从零调教、从零捞记录

选 SprintAI，让你在**一次冲刺结束后，手上一定有一套能继续判断、能继续投入的方案**
